# Specs — Tabela de andamento

Carregue a skill `specs` e execute **specs status**.

$ARGUMENTS

1. Rode `specs status [<f>]` e capture a saída mecânica.
2. Apresente a **tabela de andamento** (feature / tarefa / estado / branch /
   deps ok / ACs cobertos) em formato legível.
3. Escreva um **resumo de andamento** em parágrafo PT-BR: o que está rodando,
   o que concluiu, o que falhou, o que ainda falta para o gate.
